## 2. 引用规则

1. 正式方案优先引用**章节号或表号**（例：`报告 §7.1`、`报告表 6.4`）。
2. 确需行号时写成"`REF-MIDTERM-0830` 抽取版本行 N"（或区间）；行号只在抽取结果的 SHA-256 等于上表值时有效。
3. 附件更新或重新抽取后，必须重新生成本表并复核 PLAN/CONTRACTS 中的全部引用。

## 4. 不入库说明

- 被引用正文（`midterm-report-extracted.md`）与逐条清单（`requirements-checklist.md`）属于客户需求原文，**不进入任何 Git 提交**：本地提交产生的对象仍可能被误推、合并或打包，因此从源头避免进入历史。
- 两份文件已写入 `.git/info/exclude`，只在本机保留；`tmp/` 下的同名副本同样排除。
- 本 README 与抽取脚本可以入库：README 只记录附件编号、文件名、大小、哈希、版本与章节/表号；脚本不含正文与本机路径。

## 5. 复现方式

```
python -m pip install python-docx
python extract_midterm_docx.py <source.docx> <output.md>
```

脚本按参数取路径，只读源文件；输出为带 `[Normal] / [Heading N] / [TABLE]` 标记的行寻址文本，供上表行号对照使用。
